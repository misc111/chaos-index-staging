Meet the Models

Every forecasting style gets its own card.

Ridge

Ridge Ruler

Linear Type

Power: Noise Guard

Quiet the loud inputs without throwing away the whole scouting report.

Steady Forecast

Turns a crowded board into a calmer pregame probability.

Can keep weak signals in uniform longer than they deserve.

Elastic Net

Netty

Linear Type

Power: Balanced Grip

Keeps related baseball clues together without letting any one clue run wild.

Signal Blend

Mixes ridge patience with lasso's sharper feature discipline.

Can soften a real edge when related signals crowd together.

Lasso

Lasso Loop

Linear Type

Power: Feature Trim

Cuts clutter so the strongest pregame clues get the spotlight.

Clean Cut

Drops weak inputs and makes a leaner forecast.

Subtle matchup context can disappear if it is too quiet.

Generalized Linear Model

Starter Sheet

Linear Type

Power: Clean Read

Shows the simple relationship before penalties start negotiating.

Baseline Swing

Turns pregame features into a straight-ahead probability.

Small samples and crowded features can push it around.

Market Credibility

Halo Scout

Credibility Type

Power: Price Sense

Reads the market as a baseline before deciding what baseball adds.

Vig-Free Check

Starts from the clean price and looks for justified disagreement.

The market is a measuring stick, not the answer key.

Prior Credibility

Memory Pup

Credibility Type

Power: Memory Boost

Carries yesterday's useful read into today's game.

Prior Pull

Starts from a prior forecast and learns the justified adjustment.

Old mistakes can compound if the prior gets too much trust.

Spline

Curve Charmer

Shape Type

Power: Curve Sense

Feels when a baseball relationship needs to bend.

Bend the Line

Lets a pattern curve when a straight line is too stiff.

Pretty curves can still be dressed-up noise.

Run Margin

Margin Bridge

Shape Type

Power: Margin Bridge

Thinks about the shape of the score before picking a winner.

Score Swing

Models run margin first, then translates it to win chance.

Bad variance assumptions can warp the final probability.

Threshold Scout

Hinge Scout

Shape Type

Power: Breakpoint Radar

Looks for places where a relationship suddenly changes shape.

Hinge Hit

Marks thresholds worth testing later.

Threshold hunting can mistake random wiggles for discovery.

Neural Net

Nodeball

Neural Type

Power: Pattern Sponge

Absorbs many clues and searches for flexible combinations.

Hidden Layer

Turns tangled signals into a matchup probability.

Without enough clean data, memory can masquerade as insight.

Run Counter

Run Counter

Count Type

Power: Run Clock

Treats each team's scoring like a countable process.

Score Tally

Turns expected run counts into odds.

Chaotic pitching, weather, or scoring environments can break rhythm.

Mixed Effects

Mixed Mitt

Context Type

Power: Team Aura

Lets team context breathe around the main matchup clues.

Context Shift

Balances fixed signals with background team tendencies.

Team identity can blur into reputation if the evidence is stale.

Two Stage

Switchboard

Context Type

Power: Relay Read

Builds one baseball read before making the final call.

Double Play

Passes an intermediate signal into a second decision step.

A shaky first stage can pass bad information downstream.

Forest Vote

Forest Fork

Tree Type

Power: Many Voices

Lets lots of small decision paths vote on messy interactions.

Tree Chorus

Combines those votes into one matchup read.

Repeated noisy splits can sound more confident than they are.

Boosted Trees

Boost Bud

Tree Type

Power: Comeback Chain

Each small tree learns from the last miss.

Boost Rush

Stacks corrections into a stronger pattern read.

Can chase yesterday's error too aggressively.

Bayes Runs

Bayes Beads

Bayesian Type

Power: Uncertainty Pack

Carries uncertainty along with the run-scoring view.

Posterior Pitch

Updates the run read into a probabilistic game call.

The score model is only as sturdy as its assumptions.

Form Tracker

State Lantern

Bayesian Type

Power: Moving Form

Tracks team strength as something that changes over time.

State Shift

Turns recent form into a live pregame read.

Short hot and cold streaks can look too meaningful.
